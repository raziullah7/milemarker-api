Scope: commit c53e467 only, findings Q1-01 to Q1-08 and Q1-10. Method: a scratch copy of the repository (no `.venv`, `.git`, `node_modules`); the original environment's Python run from inside the copy as `python -m pytest` (checked: `config` imported from the copy). Each safety was removed in its own copy and the tests that should notice were run. Redis database 15 only, and only for my own scripts, which deleted their keys. One pytest process at a time.
